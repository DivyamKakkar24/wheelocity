# Vehicle Listing Requirements

## MVP Fields

### 1. Basic Vehicle Information
- Vehicle Type (Car, Bike, etc.)
- Brand (Hyundai, Honda, Toyota)
- Model (i20, City, Creta)
- Variant (Asta, Sportz, ZX, etc.)
- Year

### 2. Ownership & Usage
- Kilometers Driven
- Ownership
  - First Owner
  - Second Owner
  - Third Owner
  - Fourth Owner+

### 3. Engine & Transmission
- Fuel Type
  - Petrol
  - Diesel
  - CNG
  - Electric
  - Hybrid
- Transmission
  - Manual
  - Automatic

### 4. Pricing
- Expected Price
- Negotiable (Yes/No)

### 5. Location
- City
- State

### 6. Description
Free-text description provided by the seller.

### 7. Photos
- Minimum: 3
- Maximum: 10

Recommended photos:
- Front
- Rear
- Left Side
- Right Side
- Interior
- Dashboard
- Engine

### 8. Seller Contact
- Phone Number

---

# Important Vehicle Marketplace Terms

## Brand (Make)
Manufacturer of the vehicle.
Examples: Hyundai, Honda, Toyota

## Model
Specific vehicle line.
Examples: i20, City, Creta

## Variant
Trim level of the model.
Examples:
- Magna
- Sportz
- Asta

## Ownership
Number of previous owners.
Examples:
- First Owner
- Second Owner
- Third Owner

# Recommended MVP Flow

1. Vehicle Type, Brand, Model, Variant, Year
2. Kilometers Driven, Ownership, Fuel Type, Transmission
3. Price, Negotiable
4. City, State
5. Description, Photos
6. Publish Listing
