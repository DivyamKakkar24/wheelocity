# Used Vehicle Marketplace App Roadmap

# Phase 0 (MVP)

## Goal
Users should be able to:
- create account
- login
- post a vehicle listing
- browse vehicles
- view vehicle details
- manage their own listings

---

## Features

### Authentication
- Register
- Login
- JWT Authentication
- Protected Routes

### Vehicle Listings
- Create listing
- Edit listing
- Delete listing
- Upload vehicle images

### Explore Vehicles
- Get all listings
- Pagination
- Sort by latest

### Vehicle Details
- Single vehicle details API
- Seller information

### Search & Filters
- Search by brand/model
- Filter by:
  - brand
  - fuel type
  - price range

### User Dashboard
- View own listings
- Edit/delete own listings

---

## Suggested Build Order
1. Project setup
2. Database schema
3. Authentication
4. Create vehicle listing
5. Get all vehicles
6. Vehicle details API
7. Edit/delete listing
8. Search & filters
9. Image uploads
10. User dashboard

---

## Not Included Yet
- Chat system
- Payments
- Favorites
- Notifications
- Maps
- Admin panel
- Real-time features
- Recommendations
